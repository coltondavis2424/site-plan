Projects

Every change is kept in this browser right away, so nothing is lost if you close the page. The project file holds everything (drawings, background image, terrain, blueprints): keep it in a OneDrive, Google Drive or Dropbox folder to open it on another computer.

Backups

Kept by themselves in this browser: one when the project opens, then one every 10 minutes while you change things (the last 15). Going back to one saves the current drawing as a backup first, so it can be undone. Backups hold the drawings and settings; the background image and terrain stay as they are.
